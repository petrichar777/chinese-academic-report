# 中文课程报告生成器

一个 [Claude Code](https://claude.ai/code) 技能（Skill），严格按照**成都东软学院定制班课程报告撰写规范**，自动生成格式完整的 `.docx` 中文课程/期末报告。

## 概述

本技能可以自动生成结构完整的中文学术报告，包括：

- **封面** — 学校名称、课程信息表、提交日期
- **中文摘要** — 含关键词
- **英文摘要** — 可选
- **目录** — 带点状引导线和页码
- **正文五章** — 绪论 → 核心技术 → 进阶专题 → 前沿趋势 → 结论与心得
- **附录** — 术语表 + 指导教师评阅意见表
- **页眉页脚** — 罗马数字/阿拉伯数字页码自动切换

生成的 `.docx` 文件可直接在 Microsoft Word、WPS Office 或 Google Docs 中打开。

## 功能特点

- **格式精确** — 字体（宋体/黑体/Times New Roman）、字号（小四/五号等）、行距（1.5倍/单倍）、页边距（25mm）、缩进全部符合撰写规范
- **中英文混排** — 中文自动使用宋体/黑体，数字和英文自动使用 Times New Roman，同一段落内智能切换
- **自动目录** — 使用 Word `TableOfContents` 域，标题和页码自动生成，打开文档后右键更新即可
- **表格样式统一** — 表头行 D9E2F3 底色、细线边框、五号字体
- **图表题注规范** — 表题在上方居中，图题在下方居中
- **分节正确** — 共3节：封面（无页眉页脚）→ 前置部分（罗马数字页码）→ 正文（阿拉伯数字页码从1开始）

## 环境要求

- [Claude Code](https://claude.ai/code) 已安装并配置
- [Node.js](https://nodejs.org/)（v16 或更高版本）
- `docx` npm 包 — 技能运行时会自动安装

## 安装方式

### 方式一：注册为技能（推荐）

将整个目录复制到 skills 文件夹：

```bash
# 如果 skills 目录不存在，先创建
mkdir -p ~/.claude/skills

# 复制技能
cp -r chinese-academic-report ~/.claude/skills/
```

然后在 Claude Code 中注册：

```bash
claude skills register ~/.claude/skills/chinese-academic-report/SKILL.md
```

### 方式二：直接使用

在 Claude Code 对话中直接引用 `SKILL.md` 文件即可，技能会自动读取参考文件。

## 使用方法

### 快速开始

技能注册后，在 Claude Code 中输入以下任一关键词即可触发：

- "帮我生成一份期末报告"
- "生成一份课程报告"
- "生成定制班课程报告"
- "制作中文Word报告"
- "写一份期末总结报告"

### 需要提供的信息

技能会逐项询问以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 课程名称 | 所学课程名称 | "C++程序设计" |
| 学院 | 所在学院 | "计算机与软件学院" |
| 专业 | 所学专业 | "软件工程" |
| 班级 | 所在班级 | "软件工程22101" |
| 姓名 | 学生姓名 | "张三" |
| 学号 | 学生学号 | "2210101001" |
| 指导教师 | 指导教师姓名 | "李四" |
| 提交日期 | 报告提交日期 | "2025年6月" |
| 语言 | 报告语言 | 仅中文 / 中英双语 |

### 工作流程

技能分三个阶段运行：

1. **需求收集** — 你提供课程信息、内容偏好；技能生成章节提纲并等你确认
2. **生成脚本** — 技能编写 Node.js 生成脚本，包含所有辅助函数和格式常量
3. **运行调试** — 执行脚本生成 `.docx` 文件；常见问题（中文引号解析错误、页边距不对等）已自动规避

### 自定义修改

生成的脚本使用 `<<...>>` 占位符，可以方便地替换为实际信息：

```javascript
mkRow("学    院：", "<<学院>>"),       // 替换为你的学院
mkRow("专    业：", "<<专业>>"),       // 替换为你的专业
mkRow("学生姓名：", "<<姓名>>"),       // 替换为你的姓名
mkRow("提交日期：", "<<提交日期>>"),   // 替换为提交日期
```

你还可以：
- 编辑 `makeCh1()` 到 `makeCh5()` 函数，增删或调整章节内容
- 自定义术语表中的术语条目
- 使用 `ImageRun` 替换图片占位符为实际图片
- 调整附录中的评分标准

### 生成结果

脚本会生成一个 `.docx` 文件（约35页的报告文件大小约 50–70KB），包含：

1. 封面
2. 中文摘要
3. 英文摘要（可选）
4. 目录
5. 第1章 绪论
6. 第2章 核心技术
7. 第3章 进阶专题
8. 第4章 前沿趋势
9. 第5章 结论与心得
10. 附录A 术语表
11. 附录B 指导教师评阅意见表

## 格式规范速查

| 元素 | 中文字体 | 英文/数字字体 | 字号 | 格式 |
|------|---------|-------------|------|------|
| 正文 | 宋体 | Times New Roman | 小四 12pt | 1.5倍行距，首行缩进2字符 |
| 一级标题（章） | 黑体 | Times New Roman | 小二 18pt | 加粗，居中，另起一页 |
| 二级标题（节） | 黑体 | Times New Roman | 小三 15pt | 加粗，居左 |
| 三级标题（条） | 黑体 | Times New Roman | 四号 14pt | 加粗，居左 |
| 表格文字 | 宋体 | — | 五号 10.5pt | 居中 |
| 表头 | 宋体 | — | 五号 10.5pt | 加粗，D9E2F3 底色 |
| 页眉 | 宋体 | — | 五号 10.5pt | "成都东软学院定制班课程报告" |
| 页码 | 宋体/TNR | — | 小五 9pt | 前置部分罗马数字 / 正文阿拉伯数字 |

## 常见问题与排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 中文引号导致 `SyntaxError` | 中文 `""` 在 JS `"..."` 中被误解析 | 使用反引号模板字符串 `` p(`...`) `` |
| 首行缩进偏小 | 使用了 480 DXA | 必须使用 `firstLine: 640` |
| 表格底色变黑色 | 使用了 `ShadingType.SOLID` | 改为 `ShadingType.CLEAR` |
| Word 打不开文件 | ImageRun 缺少 type 或 PageBreak 用法错误 | 参考 `common-pitfalls.md` 第6条 |
| 页边距不对 | 使用了非标准值 | 页边距必须为 984 DXA（25mm） |
| 目录字体不正确 | 标题样式未配置正确 | 确保 H1 样式使用 FONT_HEI |

更多问题请查看 `references/common-pitfalls.md`，其中记录了 17 个已知错误及详细修复方案。
